BLOB — Style Guide

Platform: Web · Canvas: 1024×904 · Source: reference.png (+ Zune light/dark) · Icons: Lucide

Principles

1. Bloby

Pills, soft cards (24–32px), organic blob radii for brand marks and icon motifs. Prefer round over sharp.

2. Zune overflow

Oversized light lowercase headers sit on the content margin along their baseline. Ascenders and descenders may overflow that margin but must stay fully visible — never top- or bottom-clipped. Eyebrows sit tight above titles. Active = solid; idle = inactive gray.

3. Lucide

All UI icons from Lucide, thin stroke (~1.75). Place icons in circular gradient wells when decorative.

4. Busy feedback

Every control that runs async work, hits an API, or submits a form must show loading feedback: flowing pink→orange gradient (.btn-busy / BusyButton), disabled + aria-busy. Never a dead click with no motion.
